      How this demo differs from the real app

      • The original SnapLinks is a Node/Express + SQLite service that issues real HTTP 302 redirects for any slug. This page has no server, so Visit only records a simulated click locally — it never navigates anywhere.
      • Data lives in this browser tab's localStorage, scoped to this page's origin. It is not shared across devices or visible to anyone else, and clearing site data or using a private window resets it.
      • Validation, slug generation, and stats aggregation are ported line-for-line in spirit from the original src/linkService.js, just swapping better-sqlite3 queries for localStorage reads/writes.
