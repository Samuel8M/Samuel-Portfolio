This demo needs the Web Crypto API

window.crypto.subtle is not available in this page right now. Browsers only expose it in a "secure context" -- https(s) pages always qualify, and Chromium/Firefox usually also allow it for a page opened directly from file://, but that is not guaranteed by every browser or configuration. Try opening this demo through the portfolio site's real hosting (or any local http:// server) instead of double-clicking the file directly.

VaultKey

Encrypted password manager demo — AES-256-GCM with a per-vault PBKDF2-derived key, running entirely in this tab via the browser's native crypto.subtle. Nothing here is sent to a server.
