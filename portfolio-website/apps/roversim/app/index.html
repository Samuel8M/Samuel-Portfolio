RoverSim

A differential-drive robot drives a waypoint route under real-time PID heading control, reading its surroundings with five ray-cast range sensors. The physics, PID loop, and ray-casting below are a line-for-line port of the original Python simulator — every frame is actually simulated, not pre-baked.

PID: kp=2.5 ki=0.05 kd=0.4 (angular, wrapped error) drives heading toward the bearing to the current waypoint. Sensors: 5 rays at ±90°, ±45°, 0° from heading, ray-cast against the circle/rectangle obstacles below.

Vanilla JS + HTML5 Canvas, no build step. Ported from a Python differential-drive simulator — see js/kinematics.js, js/pid.js, js/sensors.js, js/world.js and js/sim.js.
