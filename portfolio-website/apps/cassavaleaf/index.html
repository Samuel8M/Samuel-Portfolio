CassavaLeaf

A cassava leaf disease classifier trained two ways on 21,000+ field images across 5 classes — a fine-tuned Vision Transformer in PyTorch, and a YOLOv8 classification model for comparison.

PyTorchVision Transformer (ViT-B/16)YOLOv8-clsComputer Vision
Why there's no live inference demo here Every other project on this page runs a genuinely working build directly in your browser. This one doesn't, on purpose: training a Vision Transformer needs a GPU and real compute time that a static portfolio page can't provide, and no trained checkpoint exists to ship client-side — faking a "working" demo with canned output would defeat the point of showing real, verifiable work. What follows is the actual pipeline and dataset instead of a prop.

Dataset

21,397 field-collected leaf images across 5 classes, split 80/20 per class into train/val. One sample per class, straight from the training set:

Source: the Kaggle Cassava Leaf Disease Classification competition dataset.

Pipeline

  • A reusable split script stratifies each class 80/20 into train/ and val/ folders.
  • torchvision.datasets.ImageFolder loads both splits directly — no CSV or manual label wiring.
  • A vit_b_16 backbone (ImageNet-pretrained) gets a fresh linear head zeroed for the 5 target classes, fine-tuned end-to-end with SGD.
  • A YOLOv8 classification model (yolov8n-cls) trains on the identical folder layout, as a faster baseline to compare against.
